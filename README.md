# Knowledge Base

> A public knowledge base where I document concepts, algorithms, technologies and software engineering topics while studying and building projects.

This repository is a collection of personal notes, practical examples and implementations created throughout my journey as a Software Engineering student and Backend Developer.

The goal is simple:

- Organize what I learn.
- Reinforce concepts by explaining them in my own words.
- Share knowledge with anyone who may find it useful.
- Build a long-term reference for future projects and studies.

## Why this repository?

I believe that writing about a subject is one of the best ways to truly understand it.

Instead of simply collecting code snippets, this repository serves as a continuously evolving knowledge base, where every note represents something I have studied, practiced or explored.

As I learn, these notes will continue to grow and improve.

---

## Important

This repository is **not intended to be a tutorial or an absolute source of truth**.

Everything here reflects **my current understanding** of each topic. If you find something inaccurate or have suggestions, feel free to open an Issue or submit a Pull Request.

Learning is a continuous process.
