
## O que é o Apache Kudu?

Pelo que deu a entender, o Apache Kudu é um sistema de armazenamento em formato de colunas gratuito e de código aberto desenvolvido para o Apache [[Hadoop]]. Ele já é meio antigo e te muitos matérias para estudo em plataformas como youtube.

O Kudo é um mecanismo destinado a dados estruturados compatível com acesso aleatório de baixa latência em escala de milissegundos a linhas individuais, juntamente com ótimos padrões de acesso analítico. É um mecanismo de big data criado para estabelecer a conexão entre o HDFS amplamente disseminado e o banco de dados HBase NoSQL.

## O que é o Hadoop Distributed File System (HDFS)?

HDFS significa Hadoop Distributed File System. O HDFS opera como um sistema de arquivos distribuído projetado para rodar em hardware comum.

O HDFS foi feito para ser tolerante a falhas e projetado para ser implantado em hardware comum e de baixo custo. O HDFS fornece acesso a dados de alto rendimento aos dados da aplicação e é adequado para aplicações que possuem grandes conjuntos de dados e permite acesso via streaming aos dados do sistema de arquivos em [Apache Hadoop](https://www.databricks.com/br/glossary/hadoop).
